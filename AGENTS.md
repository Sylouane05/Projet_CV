# Contexte du projet CV Builder

Avant toute modification, lire **[SUIVI_PROJET.md](SUIVI_PROJET.md)**, puis le README et les fichiers concernés. Ce suivi contient les décisions du propriétaire, l’état vérifié, les limites et les prochains chantiers.

- Préserver les modifications existantes et les données réelles du CV.
- Utiliser des données fictives isolées pour les tests ; ne pas publier les captures ou PDF personnels présents dans les artefacts locaux.
- Mettre à jour `SUIVI_PROJET.md` après une étape significative, en distinguant l’implémentation des vérifications réellement effectuées.
- Ne jamais consigner de secrets dans ce suivi.
